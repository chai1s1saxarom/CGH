# Синтез CGH для формирования структурированных лазерных пучков

Программа на Python рассчитывает фазовые компьютерно-генерируемые голограммы (CGH / ДОЭ) и сравнивает четыре итерационных алгоритма:

- **GS** — классический алгоритм Герчберга–Секстона (базовый метод)
- **WGS** — взвешенный GS (выравнивание интенсивности, в том числе по ловушкам массива)
- **MRAF** — IFTA со свободой амплитуды в шумовом окне
- **AW-IFTA** — предложенная модификация: MRAF + адаптивные веса + отжиг mix / damp / η

Целевые поля: круглый и квадратный top-hat, кольцо, массив 4×4. Это поля, которые нужны для лазерной обработки, аддитивных технологий и оптической метрологии.

## Запуск

```bash
pip install -r requirements.txt
python run_experiments.py
```

Результаты:

- `results/metrics.csv`, `results/metrics.json` — численные метрики
- `results/figures/` — рисунки для презентации

Параметры расчёта: сетка 512×512, 120 итераций, входной гауссов пучок, фаза-only CGH в фурье-плоскости.

## Метрики

- **η** — дифракционная эффективность, доля энергии в сигнальном окне
- **U = 1 − σ/μ** — однородность в ядре поля (для массива — по средним интенсивностям пятен)
- **RMSE** — среднеквадратичная ошибка нормированных интенсивностей в сигнальном окне
- **N\*** — итерация, на которой RMSE выходит на плато
